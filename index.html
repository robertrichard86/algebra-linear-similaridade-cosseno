📖 Metodologia

📊 TF-IDF Local

O TF-IDF (Term Frequency, Inverse Document Frequency) é um método clássico de vetorização de texto. Cada frase é transformada em um vetor esparso, onde cada dimensão corresponde a uma palavra do vocabulário. O peso de cada palavra é calculado pela frequência do termo no documento multiplicada pelo inverso da frequência do documento no corpus. A implementação é feita inteiramente em JavaScript, sem dependências externas.

🤖 Transformer Embeddings Carregando...

Os embeddings são gerados pelo modelo paraphrase-multilingual-MiniLM-L12-v2, um transformer multilingual treinado para capturar similaridade semântica. Os embeddings do dataset foram pré-calculados e salvos em JSON. Para frases do usuário, o modelo roda diretamente no navegador via Transformers.js. Cada frase é representada por um vetor denso de 384 dimensões, que captura o significado semântico do texto.
